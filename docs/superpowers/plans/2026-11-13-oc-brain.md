# Offensive Coordinator Brain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Before every player snap on Extreme, a coordinator rewrites the receivers' routes from what it has learned, counters the defense brain, and remembers across games.

**Architecture:** A pure-logic file (`src/ocbrain.c`, no game calls, tested in CI like `src/bullet.c`) holds the memory, the pick, the per-play receiver table and the file format. `src/offtools.c` glues it to the game: calls routes through the existing `apply_route`, shows the reason in `O.note`, updates the table on hot routes. `src/dbrain.c` exports zone familiarity and reports each pass result.

**Tech Stack:** C (clang, iOS arm64 dylib via GitHub Actions `make`), host `cc` for the test.

**Spec:** `docs/superpowers/specs/2026-11-12-oc-brain-design.md`

## Global Constraints

- Extreme only (`rb_get_obj_real(OBJ_MASTER, SLOT_OP_DIFFICULTY) == 4`); one log line per game when off for difficulty.
- Brain file: `$HOME/Documents/rbmod_ocbrain.txt`, saved after every lesson.
- Route indexes 0-5 are `ROUTES[]` in `src/offtools.c` (Hitch, Slant, Dig, Curl, Post, Corner); 6 = keep.
- Positions: route runners other than the back, top to bottom: first = top, last = bottom, between = middle.
- Situations: short 1-3 yards to go (also 0), medium 4-7, long 8+.
- "Worked" = `dbrain.c`'s `ok` (line ~288). Credit only the thrown-to receiver's route; runs teach nothing.
- Tunables (group "Coordinator" in `tools/tunables.json`): `oc_on` 1 (0-1, step 1), `oc_surprise` 0.2 pct (0-1, 0.05), `oc_fade` 0.9 pct (0.5-1, 0.05), `oc_counter` 1 (0-2, 0.25), `oc_keep_pct` 0.15 pct (0-1, 0.05). Generated files (`src/tune.h`, `src/tune_table.inc`, site files) are rebuilt by the hook: never edit them.
- One decision per play, nothing per frame. The back keeps his route.
- Note copy: `OC: <Route> <top|mid|low> - <reason>`, reasons: `<k> of <n> worked on <short|medium|long>`, `they haven't seen it`, `a curveball`, `the book call`.

## Review Focus

- Brain file missing, empty, garbage or another version: start empty, never crash (Task 1 test `load_rejects_junk`).
- More route runners than free routes (5 receivers): still a valid pick, duplicates allowed once routes run out (Task 1 test `full_used_still_picks`).
- Pass to the back, a lineman or nobody (`P.rcv` 0 or not in the table): no lesson (Task 1 test `table_find_missing`; Task 2 glue returns early on -1).
- Hot route after the call: the lesson credits the hot route, not the call (Task 1 test `table_set_updates`; Task 2 hot-route hook).
- A call that doesn't take (`apply_route` returns 0): table records keep (Task 2 step; checked in the phone log).

### Task 1: Pure coordinator brain with CI test

**Files:**
- Create: `src/ocbrain.h`, `src/ocbrain.c`, `tests/ocbrain_test.c`
- Modify: `Makefile` (add `src/ocbrain.c` to `SRC`, `src/ocbrain.h` to the header list), `.github/workflows/build.yml` (test step after the bullet test)

**Interfaces (Produces):**
```c
enum { OC_NROUTES = 7, OC_KEEP = 6 };
enum { OC_TOP, OC_MID, OC_BOT };
enum { OC_WHY_WORKS, OC_WHY_UNSEEN, OC_WHY_SURPRISE, OC_WHY_KEEP };
typedef struct { double att[7][3][3], ok[7][3][3], yds[7][3][3]; } OcBrain;      // [route][pos][situation]
typedef struct { double fam[9]; double surprise, keep, counter; } OcCtx;        // fam: dbrain zone familiarity 0-1
typedef struct { const void *who[6]; int route[6], pos[6], n; } OcTable;
int  oc_situation(double togo);                                   // 0 short (<=3), 1 medium (<=7), 2 long
int  oc_zone(int route, int side);                                // side 0/1/2 as dbrain; -1 for keep
int  oc_pick(const OcBrain *b, int pos, int side, int sit, const OcCtx *c, const int used[7],
             double (*rnd)(void), int *why);                      // returns route 0-6
void oc_learn(OcBrain *b, int route, int pos, int sit, int ok, double yds);
void oc_fade(OcBrain *b, double keep);                            // every count x keep
int  oc_save(const OcBrain *b, FILE *f);                          // 1 = ok; first line "ocbrain 1"
int  oc_load(OcBrain *b, FILE *f);                                // 1 = ok; on failure b is zeroed
void oc_table_reset(OcTable *t);
void oc_table_set(OcTable *t, const void *who, int route, int pos); // add, or update if present
int  oc_table_find(const OcTable *t, const void *who);              // index or -1
```

- [ ] **Step 1: Write the failing test** `tests/ocbrain_test.c` (same style as `tests/bullet_test.c`: asserts, prints `ok`). A seeded LCG `rnd()`; `OcCtx` with surprise 0, keep 0, counter 1, fam all 0 unless stated.
  - `situation_buckets`: `oc_situation(0)==0`, `(3)==0`, `(4)==1`, `(7)==1`, `(8)==2`, `(25)==2`.
  - `learned_route_wins`: slant (1) at OC_TOP medium att 10 ok 8 → `oc_pick(..OC_TOP, 0, 1..)==1`, why `OC_WHY_WORKS`.
  - `long_skips_short`: slant att 10 ok 10 at long → pick is not 0 or 1.
  - `unseen_beats_familiar`: no data; fam 1 in every zone except `oc_zone(4 /*post*/, 0)` → pick 4, why `OC_WHY_UNSEEN`.
  - `surprise_rate`: surprise 0.2, 10000 picks → count of `OC_WHY_SURPRISE` in 1800..2200.
  - `keep_rate`: keep 0.15, 10000 picks → `OC_KEEP` returned 1300..1700 times.
  - `no_duplicates`: used[1]=1 with slant best → pick != 1.
  - `full_used_still_picks`: all used[] = 1 → returns 0..6.
  - `fade_scales`: att 10 → `oc_fade(b, 0.9)` → 9 (±1e-9).
  - `file_roundtrip`: `tmpfile()`, save, rewind, load → identical `memcmp`.
  - `load_rejects_junk`: file with `junk\n` → returns 0 and brain all zero.
  - `table_set_updates` / `table_find_missing`: set (p1, 2, OC_TOP), set (p1, 5, OC_TOP) → route[find(p1)]==5, n==1; `find(p2)==-1`.

- [ ] **Step 2: Run it to make sure it fails**
Run: `cc -o build/ocbrain_test tests/ocbrain_test.c src/ocbrain.c -lm` → Expected: fails (no `src/ocbrain.c`).

- [ ] **Step 3: Implement `src/ocbrain.c`** to the interfaces above. Pick, per call:
```
r = rnd()
if r < keep                       -> OC_KEEP, why KEEP
else if r < keep + surprise       -> random route among allowed, why SURPRISE
else best score among allowed:
  score = (ok+1)/(att+2) - 0.5*counter*fam[oc_zone(route, side)]
  why = WORKS if that route has att >= 2 at this pos/sit, else UNSEEN
allowed = routes 0-5 not used[] and not (sit==long and route in {0,1});
          if empty, drop the used[] rule; if still empty, drop the long rule
```
Zones: depth bucket hitch/slant 0, dig/curl/post/corner 1 (all end under 18 yds); side: slant/dig/post move one step toward 1, corner one step away from 1 (clamped), hitch/curl stay. File: line `ocbrain 1`, then 63 lines `att ok yds`.

- [ ] **Step 3: offtools.c call.** `static void oc_call(void)` called in the `if (!O.rules_fired)` block right after the `offtools: situation` log and before `rb_rules_fire("presnap", 0)` (so scripts and hot routes act after it). It returns at once unless `T(T_OC_ON)`, Extreme, and `O.offense_snap`. It: loads the brain once (lazy; missing file = empty); detects a new game by `rb_game_controller` changing (declare `extern CInstance *rb_game_controller;`), then `oc_fade(T(T_OC_FADE))`, saves, logs `ocbrain: new game - memory x0.90`; resets the table; for each `O.rcv[i]` that isn't `O.rb`, takes position and side (side from the receiver's y against the QB's, flipped by attack direction, ±60 px, as `dbrain.c` line 248), picks with `oc_pick` (`rnd` = the mod's existing random helper), marks used, and if the pick isn't keep, `apply_route` (a 0 result records keep). Logs `ocbrain: call <top|mid|low> <route> zone <z> (<why>) vanilla path <SLOT_MY_ROUTE value>`. Sets `O.note` for the first non-surprise call, top to bottom, using the Global Constraints copy. Stores the situation for the lesson. Off-difficulty: log `ocbrain: off - not Extreme` once per game.

- [ ] **Step 4: Hot route.** After the hot route's `apply_route` (~line 449) succeeds, `oc_table_set(&table, O.rcv[O.pick], e - 1, <that receiver's position>)`.

- [ ] **Step 5: Lesson.** `rb_off_oc_lesson`: find `rcv` in the table (-1 → return), `oc_learn` with the stored situation, save the file, log `ocbrain: lesson <route> <pos> <sit> ok=<0|1> yds=<y>`.
